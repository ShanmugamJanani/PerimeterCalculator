**Perimeter Calculator 📐**

An Android application developed using Android Studio to easily calculate the perimeters of various geometric shapes.

**Features**

Shape Support: Calculate perimeters for standard shapes including Squares, Rectangles, Circles, and more.

User-Friendly Interface: Simple and intuitive input fields for entering shape dimensions.

Instant Results: Quickly compute accurate perimeter measurements.

**Tech Stack**

Language: Java / Kotlin (Android)

IDE: Android Studio

Build System: Gradle (build.gradle.kts)
